Add the `[visual_model]` config section for binding image / screenshot / video inspection to a separately configured vision-capable companion model. Set `model` in `config.toml` (or `KIMI_VISUAL_MODEL`) to pin the visual model; `default_effort` (or `KIMI_VISUAL_EFFORT`) sets its thinking effort.
